# Vehicle Pass Background Images

Place the following background images in this directory:

1. **volunteer_vehicle_pass.png** - For volunteers (समयदानी कार्यकर्ता)
2. **organization_vehicle_pass.png** - For organization representatives (संगठन प्रतिनिधि)  
3. **participant_vehicle_pass.png** - For participants (प्रतिभागी)

## Image Specifications:
- **Size**: 10cm x 5cm (1134x567 pixels at 300 DPI)
- **Format**: PNG with transparency support
- **Margins**: 
  - Top: 0.9cm
  - Bottom: 0.5cm
  - Left/Right: 0.5cm
  - QR area: 1.9cm x 1.5cm (bottom right)

## Design Guidelines:
- Leave content area clear for text overlay
- Use appropriate colors for each user type
- Ensure good contrast for text readability
- Include subtle branding elements if needed
